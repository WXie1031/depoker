# LAN Hold'em

一个零依赖的局域网页版无限注德州扑克，支持 2-10 人、四位数字房间、房主管理、机器人玩家、国际通用德扑规则和雀魂风格的轻量 UI。

## 快速开始

```bash
npm start
```

启动后终端会输出本机与局域网地址。所有玩家在浏览器打开同一个局域网地址，输入同一个四位数字房间号即可进入同一房间。第一个进入者自动成为房主。
如需更换端口，可用 `PORT=8080 npm start`。

## 功能

- 👥 **2-10 人对局**：基于 Server-Sent Events 的实时状态同步，局域网内动作响应快。
- 🏠 **房间模型**：四位数字房间号；房主可踢人，玩家可自行离开。
- 🤖 **机器人玩家**：支持稳健 / 均衡 / 激进三种风格，可在开局前配置数量（最多 9 个，总人数不超过 10）。
- 🎴 **国际通用规则**：翻牌前/翻牌/转牌/河牌、大小盲、最小加注、全下、边池与摊牌。
- 📏 **固定牌桌尺寸**：牌桌高度固定，不随牌局记录增长；牌局记录支持上下拖拉查看。
- ⚡ **性能优化**：无前端框架、无第三方依赖，静态资源自动 gzip（合计约 10KB），动作只同步必要状态。

## 技术说明

- 后端：Node.js 原生 `http` + SSE，无外部运行时依赖。
- 前端：原生 HTML/CSS/JS，使用系统字体与 Unicode 公共图标，保证加载速度和统一风格。
- 游戏引擎：独立模块，包含牌型评估、下注状态机、边池结算和机器人决策。
- 机器人：内置启发式策略（翻牌前牌力 + 翻牌后成牌强度 + 底池赔率 + 风格参数），不依赖外部 AI 服务，也不会访问其他玩家底牌。
